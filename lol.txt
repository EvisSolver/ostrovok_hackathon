# 🗺️ Схема Базы Данных (PostGIS Models)

Документация всех моделей и таблиц из файла [`app/models.py`](file:///home/miro/git/otters/app/models.py).

---

## 📌 Общий обзор таблиц

| Таблица (`__tablename__`) | Модель Python | Что хранит | Тип геометрии |
| :--- | :--- | :--- | :--- |
| **`hotels`** | `Hotel` | Отели, гостиницы, хостелы, цены и звезды | `POINT` (Точка) |
| **`green_zones`** | `GreenZone` | Парки, скверы, реки, озера, каналы | `POINT` (Центроид) |
| **`roads`** | `Road` | Дороги, шоссе, проспекты, МКАД | `LINESTRING` (Линия) |
| **`attraction`** | `Attraction` | Достопримечательности, памятники, музеи | `POINT` (Точка) |
| **`shop_malls`** | `Shop_malls` | Торговые центры, моллы, магазины | `POINT` (Точка) |
| **`where_to_eat`** | `Where_to_eat` | Рестораны, кафе, бары, фастфуд | `POINT` (Точка) |

> 🌍 **Все гео-поля (`location`)**:
> - Тип: `Geography(..., srid=4326)` (стандарт WGS 84).
> - Порядок координат: **`(долгота, широта)` / `(lon, lat)`**.
> - Все расчеты расстояний (`ST_Distance`, `ST_DWithin`) производятся **в метрах**.

## 🏨 1. Таблица `hotels` (Отели)
*Модель в коде:* `app.models.Hotel`  
*Назначение:* Хранит информацию о местах проживания в Москве (отели, хостелы, апартаменты).

| Поле | Тип в БД | Python тип | Nullable | Primary Key | Описание / Пример |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **`id`** | `BigInteger` | `int` | ❌ Нет |  Да | Уникальный ID объекта из OSM (например, `326097461`) |
| **`name`** | `String` | `str` |  Да | ❌ Нет | Название отеля (например, `"Radisson Blu"`, `"Хостел Рус"`) |
| **`stars`** | `Integer` | `int` |  Да | ❌ Нет | Количество звезд (от `1` до `5`). Если не указано — `NULL` |
| **`price`** | `Integer` | `int` |  Да | ❌ Нет | Стоимость за ночь в рублях (например, `4500`, `12000`) |
| **`location`** | `Geography(POINT, 4326)` | `str` / WKT | ❌ Нет | ❌ Нет | Координаты отеля: `POINT(lon lat)` |

*Назначение:* Дорожная сеть Москвы. Используется для расчета уровня шума и доступности транспорта.

| Поле | Тип в БД | Python тип | Nullable | Primary Key | Описание / Пример |

| **`name`** | `String` | `str` |  Да | ❌ Нет | Название улицы / шоссе (например, `"Ленинский проспект"`) |
| **`highway_type`** | `String` | `str` | ❌ Нет | ❌ Нет | Категория дороги (`motorway`, `trunk`, `primary`, `secondary`) |
| **`location`** | `Geography(LINESTRING, 4326)` | `str` / WKT | ❌ Нет | ❌ Нет | Траектория дороги: `LINESTRING(lon1 lat1, lon2 lat2, ...)` |
