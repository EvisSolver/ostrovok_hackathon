# Hotel Photo Parser

Python 3.11+. Получает ссылки на фотографии отеля из **Google Картинок**,
при нехватке результатов дополняет их из **Bing Images**. По желанию скачивает
изображения. API-ключ не нужен.

## Установка

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
```

## Запуск

```bash
python hotel_photos.py "Hilton Berlin" --limit 10
python hotel_photos.py "Hilton Berlin" --limit 10 --download
python hotel_photos.py "The Ritz-Carlton Moscow" --limit 5 --headed
```

В консоль выводится JSON с полями `url`, `source`, `title`, `page_url`,
`is_thumbnail` и `saved_as` (если изображение удалось скачать).

- `--download` — сохраняет изображения в `photos/название_отеля/`.
- `--output ПУТЬ` — меняет родительскую папку для скачивания.
- `--headed` — запускает видимый браузер (полезно при отладке).
- Логи — в `hotel_photos.log` **рядом с `hotel_photos.py`**, независимо от
  текущей рабочей папки; ротация после 2 МБ, хранение трёх архивов.

Фотографии из Google могут быть уменьшенными превью (`is_thumbnail: true`),
поскольку страница поиска не всегда раскрывает URL оригинала. Bing обычно
возвращает прямые ссылки на оригинал. Сайты могут отклонять скачивание,
удалять изображения или требовать подтверждение, поэтому отдельные файлы
могут не скачаться; причины записываются в лог.

## Ограничения

Google и Bing меняют HTML и могут показывать капчу/страницу согласия. В этом
случае поиск по недоступному источнику пропускается. Скрипт не обходит капчу
и не использует прокси. Используйте умеренное число запросов.

Содержимое результатов поиска не гарантирует, что фотография действительно
принадлежит названному отелю. При совпадении названий уточните город и адрес
в поисковой строке. У изображений могут быть авторские права — проверяйте
условия использования перед публикацией.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют обработку данных без доступа к Google или Bing.
