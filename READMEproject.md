# Как устроен фронтенд

Короткая карта фронтенда сервиса подбора отелей: стек, компоненты и то, как данные
ходят между браузером, API и нейронкой. Код лежит в `hotel-provider/src`.

## Стек

| Слой | Технология | Зачем |
|---|---|---|
| UI | React 18 | компоненты, состояние чатов и каталога |
| Сборка | Vite 5 | dev-сервер с прокси `/api` → `localhost:8000`, продакшн-сборка в `dist/` |
| Стили | Sass (SCSS-партиалы) | дизайн-токены в `_variables.scss`, тема — в `_brand-refresh.scss` |
| Роутинг | react-router-dom 6 | страницы `/`, `/hotels/:slug`, 404 |
| Карты | leaflet + react-leaflet | карта отеля и соседних мест |
| Markdown | react-markdown + remark-gfm | рендер ответов нейронки (списки, таблицы), без исполнения HTML |

Запуск разработки: `npm install && npm run dev` (бэкенд поднимается отдельно, см.
`hotel-provider/docker-compose.yml` — он собирает весь стенд, включая базы и LLM).

## Структура

```
src/
├── main.jsx              # входная точка, роутер
├── App.jsx               # маршруты, общий Layout
├── pages/
│   ├── HomePage.jsx      # первый экран с чатом + каталог с фильтрами
│   ├── HotelPage.jsx     # страница отеля: фото, описание, карта, соседние места
│   └── NotFoundPage.jsx
├── components/           # см. таблицу ниже
├── services/
│   ├── chatApi.js        # общение с сервером чатов (SSE-стриминг, история, ретраи)
│   └── hotelsService.js  # каталог: постраничные запросы с фильтрами
├── data/
│   └── hotelSchema.js    # normalizeHotel(): дефолты полей + расчёт минут пешком
├── utils.js              # formatPrice, plural, walkMinutes
└── styles/               # main.scss собирает партиалы: base, layout, hero, home,
                          # hotel, chat, chat-shortlist, chat-md, brand-refresh
```

## Компоненты

| Компонент | Роль |
|---|---|
| `Layout` | шапка, подвал, общая обёртка страниц |
| `HeroChat` | главный чат на первом экране: подсказки-промпты, стриминг ответа, учёт фильтров каталога |
| `ChatWidget` | компактный чат-виджет на странице отеля (вкладки «ИИ-помощник» / «Поддержка») |
| `ChatMarkdown` | рендер Markdown-ответа нейронки: заголовки, списки, сравнительная таблица |
| `ChatHotelLinks` | «подборка помощника» под ответом: звёзды, цена, кусочек описания, пометки «что рядом», ссылки на отели |
| `HotelCard` | карточка отеля в каталоге: фото, звёзды, подпись из описания, цена |
| `CoverImage` | фото с заглушкой «Фото не найдено» (URL внешние, обрабатывает и ошибку загрузки) |
| `Stars` | звёзды категории (SVG) |
| `Filters` | панель фильтров каталога: звёзды, цена, расстояния до парка/воды/метро и т.п. |
| `HotelTicker`, `HotelTickerCard` | «бегущие» колонки отелей по бокам первого экрана |
| `HotelMap` | Leaflet-карта на странице отеля |
| `Section` | обёртка секции с заголовком |

## Как ходят данные

1. **Каталог.** `HomePage` → `hotelsService.getHotels()` → `GET /api/hotels`
   с фильтрами и номером страницы. Сервер отвечает страницей из PostGIS-каталога;
   `normalizeHotel()` дополняет поля по схеме. Карточка показывает фото из
   `hotels.photo_url` (поле `cover`), при пустом URL — «Фото не найдено».

2. **Чат с ИИ.** `HeroChat`/`ChatWidget` → `chatApi.askAI()` →
   `POST /api/chat/stream` (Server-Sent Events):
   - `token` — кусок текста ответа (дописывается в сообщение на лету);
   - `done` — финал: `hotels` — подборка для `ChatHotelLinks` (сервер уже заменил
     ID из JSON нейронки на названия, звёзды, цены и пометки из базы);
   - `busy`/`error` — перегрузка или сбой, клиент ретраит сам.
   Ответ бота рендерится через `ChatMarkdown`. Чат не прокручивается сам —
   пользователь листает ленту вручную.

3. **Идентификатор посетителя** живёт в памяти вкладки (`chatApi.getUserId()`):
   перезагрузка страницы (F5) начинает переписку с чистого листа, переходы
   внутри сайта историю сохраняют.

4. **Страница отеля.** `GET /api/hotels/{slug}` отдаёт карточку с описанием,
   фото и ближайшими местами (парк, вода, достопримечательность, еда, дорога) —
   их же видно на карте.

## Договорённости

- Названия, цены и расстояния в ответах ИИ берутся только из базы; тексты
  описаний — генерированные (см. `scripts/enrich_hotels_db.py`).
- Цены — mock: на странице отеля это подписано.
- Фото — внешние ссылки (Wikipedia/Wikimedia, собирает
  `DownloadPhotoHotelParser/batch_photos.py`); битая ссылка на фронте
  превращается в заглушку.
