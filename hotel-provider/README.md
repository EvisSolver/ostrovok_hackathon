# Отели России — Сервис подбора и бронирования с ИИ

Полнофункциональный веб-сервис для поиска и бронирования отелей по всей России с интеграцией мультиагентной нейросети-консультанта.

Каталог сайта читает таблицу `hotels` из основной PostGIS-БД (`id`, `name`, `stars`, `price`, `location`). Строки с пустыми именами и `Unknown` (без учёта регистра и пробелов) исключаются до подсчёта и пагинации. Каталог загружается страницами до 25 отелей; сервер поддерживает фильтры близости к паркам, водоёмам, рекам, дорогам, достопримечательностям, торговым центрам и местам питания через PostGIS, расстояния задаются в метрах. Для карточек API формирует стабильный `hotel-{id}` slug и возвращает только присутствующие в таблице сведения; поля города, фотографий, описания и цены остаются пустыми, если их нет в БД. Логика чата по-прежнему использует `public/data/hotels.json` и этой интеграцией не меняется.

      └─────────────────┘             │                       │

### Основные компоненты:
1. **Фронтенд (`src/`)**:
   * **Первый экран (Hero Screen):** бесшовный сквозной дизайн в стиле современных нейросетей (ChatGPT, Claude) на 100vh.
   * **Прыгающие тикеры отелей:** левая и правая колонки с крупными векторными карточками, двигающимися дискретными шагами с пружинной анимацией (`cubic-bezier(0.34, 1.56, 0.64, 1)`).
   * **Умный чат:** быстрые подсказки, индикатор «Нейросеть думает... •••», невидимая подмешка фильтров каталога к запросу пользователя.
   * **Каталог отелей:** серверная пагинация до 25 записей и фильтры по звёздам, цене и близости объектов из PostGIS.
2. **Бэкенд чатов (`server/app.py`)**:
   * FastAPI сервер с потоковым SSE-эндпоинтом `/api/chat/stream`.
   * Функция `stream_model`: обращается к Docker-микросервису нейросети по `LLM_SERVICE_URL`.
   * Поддержка CORS, лимитирование запросов (rate limiter), управление очередью слотов.
3. **Мультиагентная нейросеть (`LLM/`)**:
   * Цепочка из 3 нейросетевых агентов (`REQUEST_BUILDER` → `DATA_FETCHER` → `ANSWER_COMPOSER`).
   * Обернута в FastAPI микросервис на порту `8001` (`POST /generate`, `GET /health`).

## Быстрый старт через Docker Compose (Рекомендуемый)

Стенд поднимает сайт и чат: **Nginx (8080) + 3 воркера API + LLM-микросервис (8001) + PostgreSQL истории чата**. Каталог сайта читается из таблицы `hotels` основной PostGIS-БД через `HOTELS_DATABASE_URL`.

```bash
# 1. Перейдите в папку проекта и соберите фронтенд
cd hotel-provider
npm run build

# 2. Укажите PostgreSQL с таблицей hotels основной БД.
# Для основного Compose из корня репозитория:
export HOTELS_DATABASE_URL=postgresql://otters:hackathon@host.docker.internal:5432/otters_db

# 3. Запустите все сервисы в фоне
docker compose up -d --build
```

После старта откройте в браузере:
👉 **http://localhost:8080**

Остановка стенда:
```bash
docker compose down
```

## Режим разработки (без Docker)

### 1. Запуск микросервиса нейросети:
```bash
cd hotel-provider/LLM
pip install -r requirements.txt
uvicorn server_llm:app --host 0.0.0.0 --port 8001
```

### 2. Запуск бэкенда (FastAPI):
```bash
cd hotel-provider/server
pip install -r requirements.txt
uvicorn app:app --port 8000 --reload
```

### 3. Запуск фронтенда (Vite):
```bash
cd hotel-provider
npm install
npm run dev
```
Фронтенд разработки доступен на **http://localhost:5173**.

## API каталога

`GET /api/hotels` возвращает `{ items, total, page, pageSize, totalPages }`; `page_size` ограничен 25. Поддерживаются параметры `q`, `stars` (список через запятую), `max_price`, `sort` (`stars`, `price-asc`, `price-desc`, `id`), `page`, `page_size` и пространственные радиусы в метрах: `park_distance_m`, `water_distance_m`, `river_distance_m`, `road_distance_m`, `attraction_distance_m`, `mall_distance_m`, `food_distance_m`. Если заданы несколько proximity-параметров, рядом должны присутствовать все выбранные типы объектов. Успешные страницы кэшируются ограниченным TTL/LRU-кэшем.

## Команды для самостоятельного тестирования

### 1. Проверка микросервиса нейросети (порт 8001)
* **В браузере:** откройте интерактивную панель Swagger UI: **http://localhost:8001/docs**
* **Через терминал (`curl`):**
  ```bash
  curl -X POST http://localhost:8001/generate \
    -H "Content-Type: application/json" \
    -d '{"message": "15 + 15"}'
  ```

### 2. Проверка потокового эндпоинта бэкенда (порт 8080)
```bash
curl -N -X POST http://localhost:8080/api/chat/stream \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "user-test-12345",
    "channel": "ai",
    "message": "2 + 2",
    "context": {"path": "/"}
  }'
```
В терминал вернется поток Server-Sent Events (SSE) с ответом от нейросети:
```text
event: token
data: {"t": "14 * 0 = 0"}

event: done
data: {"hotels": []}
```

### 3. Проверка статуса контейнеров Docker Compose
```bash
docker compose ps
```
Все 6 контейнеров (`nginx`, `api-1`, `api-2`, `api-3`, `llm-1`, `db-1`) должны иметь статус `Up (healthy)`.
